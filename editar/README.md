# Archivos editables de martinlaportilla.com

Toca un archivo, pulsa el lápiz, cambia lo que necesites y guarda con **Commit changes**. La web se actualiza en 1–2 minutos.

| Archivo | Qué cambia en la web |
| --- | --- |
| [conciertos.csv](conciertos.csv) | Próximos conciertos (los pasados se ocultan solos) |
| [proyectos.csv](proyectos.csv) | Proyectos: grupos, estilos, giras e Instagram |
| [videos.csv](videos.csv) | Vídeos de YouTube de la sección Música |
| [musica.csv](musica.csv) | Temas de Spotify y Apple Music |
| [galeria.csv](galeria.csv) | Fotos de la galería (la primera es la destacada) |
| [equipo.csv](equipo.csv) | Bajos, preamp y cuerdas |
| [bio.txt](bio.txt) | Biografía en los cuatro idiomas |
| [textos-portada-servicios.txt](textos-portada-servicios.txt) | Textos de la sección «Clases y grabaciones» de la portada |
| [textos-pagina-clases.txt](textos-pagina-clases.txt) | Todos los textos de la página de Clases |
| [textos-pagina-grabacion.txt](textos-pagina-grabacion.txt) | Todos los textos de la página de Grabación |
| [hoja.txt](hoja.txt) | Opcional: enlace a una hoja de Google para los conciertos |

**En las tablas (.csv):**

- La primera línea son los títulos de las columnas: no la cambies.
- Una línea por elemento, con los datos separados por comas.
- Si un texto lleva una coma dentro, escríbelo entre comillas dobles: `"Argentina 2007, 2009 y 2018"`.
- El orden de las líneas es el orden en la web (salvo los conciertos, que se ordenan por fecha).
- Fechas de conciertos: día/mes/año, por ejemplo `15/01/2027`.

**En los archivos de textos (.txt):** cada texto tiene su nombre entre corchetes, por ejemplo `[c_book]`, y debajo una línea por idioma: `es: Reservar clase`. Cambia solo lo que va después de `es:`, `en:`, `ca:` o `pt:`.

**Las fotos** se suben a la carpeta `img/galeria` (Add file → Upload files) antes de añadirlas a galeria.csv.

**Si algo sale mal:** abre el archivo, toca *History* y vuelve a copiar la versión anterior.
